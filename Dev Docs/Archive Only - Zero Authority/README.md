# Archive Only - Zero Authority

Everything in this directory is retained only for implementation provenance, architectural history, and investigation of past decisions.

These files are not current specifications, plans, status reports, task lists, path maps, or implementation instructions. Their module paths, version numbers, dependencies, sequencing, acceptance criteria, and statements about what is implemented may be obsolete or wrong.

Rules:

- Do not read this archive during normal implementation, planning, review, or debugging.
- Consult it only when explicitly investigating historical intent, implementation lineage, or why a current design decision was made.
- Never use an archived document to override live code, tests, `AGENTS.md`, or retained current documentation.
- Never resume work from an archived checklist or "next steps" section.
- Verify every historical claim against the current repository before relying on it.
- Archived documents have zero authority over present or future implementation.
